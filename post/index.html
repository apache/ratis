    Release 3.3.0 is available

    2026 Aug 12

    Download

    This is a minor release that adds DataStream streaming reads and first-class OpenTelemetry tracing support. It also includes improvements to linearizable reads, Raft replication, snapshot handling, TLS configuration, resource management, APIs, and operational tooling. See the changes between 3.2.2 and 3.3.0 releases.

    It has been tested with Apache IoTDB.
