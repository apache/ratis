[Download](https://ratis.apache.org/downloads.html)

This is a minor release that adds DataStream streaming reads and first-class OpenTelemetry tracing support. It also includes improvements to linearizable reads, Raft replication, snapshot handling, TLS configuration, resource management, APIs, and operational tooling.
See the [changes between 3.2.2 and 3.3.0](https://github.com/apache/ratis/compare/ratis-3.2.2...ratis-3.3.0) releases.

It has been tested with [Apache IoTDB](https://iotdb.apache.org).
